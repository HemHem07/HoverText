# HoverText

HoverText is a lightweight macOS menu-bar scratchpad for quickly capturing text and images without leaving your current app.

## Features

- Global keyboard shortcut for opening and closing Quick Capture
- Text and pasted-image capture
- Automatic window growth for larger images
- Saved capture history
- Reopen saved captures as editable drafts
- Delete individual captures
- Automatic cleanup after 1, 7, or 30 days, or keep captures forever
- Configurable shortcut, window position, window size, Escape behavior, and launch at login

## Requirements

- macOS 26.2 or later
- A recent version of Xcode

## Run from Xcode

1. Open `HoverText.xcodeproj` in Xcode.
2. Select the **HoverText** scheme and **My Mac** as the destination.
3. Press **Run** (`⌘R`).
4. Look for the square-and-pencil icon in the menu bar.

The default shortcut is `Control + Option + C`. You can change it in **Settings**.

## Saving

- Invoke the shortcut again to save the current capture and close it.
- Use the top-right button to save and start a new capture.
- Use the top-left **×** button to discard the current capture.
- Open **History** from the menu-bar menu to view, reopen, or delete saved captures.

Captures are stored locally in your user Application Support folder. They are not uploaded anywhere by HoverText.

## Repository notes
